# Migrating to Swarm 0.7.0

0.7.0 is a breaking release. Each section below is self-contained and covers one
change set.

## Deprecated API removed

Every declaration marked `@available(*, deprecated)` in 0.6.x has been removed,
along with the hollow `SwarmMembrane` library product. Each removed symbol has a
replacement that shipped in 0.5 or 0.6, so upgrading is a rename or a small
call-site change. Building against 0.6.x with deprecation warnings enabled shows
every call site you need to touch.

### Package products

| Removed | Use instead |
|---|---|
| `SwarmMembrane` product (`@_exported import Swarm`, `SwarmMembraneProduct`) | Depend on `Swarm` and `import Swarm`. Membrane adapters (`MembraneEnvironment`, `MembraneAgentAdapter`, …) live in `Swarm` with the `Integrations` trait. |

### Agent and configuration

| Removed | Use instead |
|---|---|
| `Agent.Builder` (`Agent.Builder().instructions(…).build()`) | `Agent(_:…)` initializers, `withTools(_:)`, `withHandoffs(_:)` |
| `FoundationModelsExecutionMode`, `AgentConfiguration.foundationModelsExecution`, `.foundationModelsExecution(_:)` builder | Nothing — the flag was already ignored. Opt into a provider-owned loop with `.foundationModelsOwningToolLoop()`. Drop the argument from `AgentConfiguration(…)`. |
| `AgentError.toolExecutionFailed(toolName:underlyingError:)` | `AgentError.toolFailure(toolName:message:cause:)` |

### Context

| Removed | Use instead |
|---|---|
| `AgentContextKey` and `AgentContext.get(_: AgentContextKey)` / `set(_: AgentContextKey, value:)` | Typed `ContextKey` statics: `get(.originalInput)`, `set(.previousOutput, value)`. For the wire name use `ContextKey<String>.originalInput.name`. |
| `AgentContextProviding` and `AgentContext.setTyped(_:)` / `typed(_:)` / `removeTyped(_:)` / `hasTyped(_:)` | Declare a `ContextKey<Value>` and use `setTyped(_:value:)` / `getTyped(_:)` |

```swift
// 0.6
struct UserPrefs: AgentContextProviding { static let contextKey = "prefs"; var theme: String }
await context.setTyped(UserPrefs(theme: "dark"))
let prefs = await context.typed(UserPrefs.self)

// 0.7 (the value must be Codable)
struct UserPrefs: Codable, Sendable { var theme: String }
let prefsKey = ContextKey<UserPrefs>("prefs")
await context.setTyped(prefsKey, value: UserPrefs(theme: "dark"))
let prefs = await context.getTyped(prefsKey)
```

### Handoffs

| Removed | Use instead |
|---|---|
| `HandoffReceiver` | Override `handleHandoff(_:context:session:observer:)` on any `AgentRuntime` |
| `HandoffConfiguration` / `AnyHandoffConfiguration` `init(…, nestHandoffHistory: Bool)` | `init(…, history: .nested)` or `history: .none` (`nestHandoffHistory` remains as a read-only projection) |

### Tool results and guardrails

| Removed | Use instead |
|---|---|
| `ToolResult.init(callId:isSuccess:output:duration:errorMessage:)` | `ToolResult.success(callId:output:duration:)` / `.failure(callId:error:duration:)` |
| `ToolCallRecord.init(…, isSuccess:errorMessage:)` | `ToolCallRecord.success(toolName:arguments:result:…)` / `.failure(toolName:arguments:error:…)` |
| `GuardrailResult.init(tripwireTriggered:outputInfo:message:metadata:)` | `GuardrailResult.passed(message:outputInfo:metadata:)` / `.tripwire(message:outputInfo:metadata:)` |

Codable decoding of the historical `isSuccess` / `tripwireTriggered` JSON shape is
unchanged; only the Swift initializers were removed.

### Providers

| Removed | Use instead |
|---|---|
| `ConversationInferenceProvider`, `StreamingConversationInferenceProvider`, `ToolCallStreamingConversationInferenceProvider`, `StructuredOutputConversationInferenceProvider` | Conform to `InferenceProvider` and implement the `messages:` methods |
| `CapabilityReportingInferenceProvider` | Declare `capabilities` on `InferenceProvider` |
| `PromptTokenCountingInferenceProvider` | Conform to `PromptTokenCounter` and return it from `promptTokenCounter` |
| `StructuredOutputInferenceProvider` | Advertise `.structuredOutputs` and implement `generateStructured(messages:request:options:)` |
| `ToolCallStreamingInferenceProvider` | Advertise `.streamingToolCalls` and implement `streamWithToolCalls(messages:tools:options:)` |
| `InferenceProviderCapabilities.inferred(from:)` | `InferenceProviderCapabilities.resolved(for:)` |
| `InferenceMessage.init(role:content:name:toolCallID:toolCalls:attachments:)` | `InferenceMessage(body:)` or `.system(_:)`, `.user(_:)`, `.assistant(_:toolCalls:)`, `.tool(name:content:toolCallID:)` |

```swift
// 0.6
actor MyProvider: InferenceProvider, PromptTokenCountingInferenceProvider { … }

// 0.7
actor MyProvider: InferenceProvider, PromptTokenCounter {
    nonisolated var promptTokenCounter: (any PromptTokenCounter)? { self }
    func countTokens(in text: String) async throws -> Int { … }
}
```

### Observers

| Removed | Use instead |
|---|---|
| `AgentObserver.onLLMStart(context:agent:systemPrompt:inputMessages: [MemoryMessage])` | The `[InferenceMessage]` overload of `onLLMStart`. Observers that only implemented the `MemoryMessage` variant no longer receive the callback. |

### Memory

| Removed | Use instead |
|---|---|
| `MemorySessionLifecycle` | Implement `beginMemorySession()` / `endMemorySession()` on your `Memory` |
| `MemorySessionReplayAware` | Implement `importSessionHistory(_:)` on your `Memory` |
| `MemoryRetrievalPolicyAware` | Implement `context(for: MemoryQuery)` on your `Memory` |
| `MemorySessionImportPolicy` | Implement `allowsAutomaticSessionSeeding` on your `Memory` |
| `MemoryPromptDescriptor` (`memoryPromptTitle`, `memoryPromptGuidance`, `memoryPriority`) | Return `MemoryPromptMetadata(title:guidance:priority:)` from `memoryPromptMetadata` |
| No-backend `Memory.persistent(conversationId:maxMessages:)` | `.persistent(backend:conversationId:maxMessages:)` with `SwiftDataBackend.persistent()` (Apple) or `InMemoryBackend()` |
| `WaxIntegration` | `IntegrationsTrait.isEnabled`, `WaxMemory`, or `WaxEmbeddingProviderAdapter` |

All of the replacement requirements have defaults, so most conformers just
delete the marker protocol from their conformance list.

### Workflows

| Removed | Use instead |
|---|---|
| `Workflow.MergeStrategy.first` | `.firstCompleted` |
| `Workflow.durable.checkpoint(id:policy:)` + `.durable.checkpointing(_:)` | `.durable.configured(id: WorkflowCheckpointID("…"), store: …, policy: …)` |
| `Workflow.durable.execute(_:resumeFrom:)` / `.durable.run(_:resumeFrom:)` | `DurableWorkflow.execute(_:)` / `.resume(_:from:)` |
| `Workflow.durable.fallback(primary:to:retries:)` | `Workflow().fallback(primary:to:retries:)` |
| `WorkflowError.checkpointStoreRequired` | Not needed: `configured(id:store:policy:)` requires a store at the type level |

```swift
// 0.6
let result = try await Workflow()
    .step(fetch).step(analyze)
    .durable.checkpoint(id: "weekly-report", policy: .everyStep)
    .durable.checkpointing(.fileSystem(directory: url))
    .durable.execute("go", resumeFrom: "weekly-report")

// 0.7
let durable = Workflow()
    .step(fetch).step(analyze)
    .durable
    .configured(id: WorkflowCheckpointID("weekly-report"), store: .fileSystem(directory: url), policy: .everyStep)
let fresh = try await durable.execute("go")
let resumed = try await durable.resume("go", from: WorkflowCheckpointID("weekly-report"))
```

### Renamed typealiases

| Removed | Use instead |
|---|---|
| `MCPServer` | `MCPServerConnection` |
| `Retry` | `RetryPolicy` |
| `Fallback` | `FallbackChain` |
