# Migrating to Swarm 0.7.0

0.7.0 is a breaking release. Each section below is self-contained and covers one
change set.

## Agent entry points

`Agent` now has two public initializers:

1. **Canonical:** `Agent(_ instructions: String, configuration:, memory:, inferenceProvider:, tracer:, inputGuardrails:, outputGuardrails:, guardrailRunnerConfiguration:, handoffs:) { tools }`.
   Use it by default. The trailing `@ToolBuilder` closure accepts typed `Tool`
   values, `[any Tool]` arrays, `FunctionTool`, built-in tools, `if`, and `for`.
2. **Advanced:** `Agent(tools: [any AnyJSONTool], instructions:, configuration:, ...)`.
   Use it for tool lists assembled at runtime as `any AnyJSONTool` values, such
   as MCP-bridged tools or registries.

Five convenience initializers were removed:

| Removed | Use instead |
|---|---|
| `Agent(provider, instructions: "…")` (unlabeled provider first) | `Agent("…", inferenceProvider: provider)` |
| `Agent("…", provider: p) { … }` | `Agent("…", inferenceProvider: p) { … }` |
| `Agent(tools: [typedTool], instructions: "…")` (`[some Tool]`) | `Agent("…") { typedTool }`, or `Agent("…") { toolsArray }` for `[any Tool]` |
| `Agent(name: "Billing", instructions: "…", …)` | `Agent("…", configuration: .default.name("Billing"), …)` |
| `Agent(…, handoffAgents: [billing, support])` | `Agent(…, handoffs: [billing.asHandoff(), support.asHandoff()])` |

`asHandoff()` produces the same configuration `handoffAgents:` built: default
tool name, no description, and `history: .none`. Use `asHandoff { $0.name("…") }`
to give two agents of the same type distinct tool names.

The labeled `Agent(instructions: "…", inferenceProvider: …)` form still works
through the advanced initializer, but prefer the canonical one.

`Job` is unchanged in this release.
